# XIVLauncher

XIVLauncher (или XL) - это более быстрый лаунчер для FINAL FANTASY XIV с дополнительными возможностями и улучшениями качества жизни.

## Что это дает

- Автовход
- Быстрое скачивание и установка патчей
- Поддержка плагинов Dalamud
- Дополнительные функции интерфейса и удобства

## Установка

1. Скачайте `Setup.exe` со страницы релизов:  
   <https://github.com/goatcorp/FFXIVQuickLauncher/releases/latest>
2. Запустите установщик.
3. После установки запустите XIVLauncher из меню "Пуск".

Удалить приложение можно через "Приложения и возможности" в Windows или через контекстное меню ярлыка в меню "Пуск".

## Важно

Если при установке или запуске возникают ошибки, сначала проверьте антивирус. Некоторые антивирусы ошибочно определяют XIVLauncher как угрозу. Инструкции по исключениям есть в FAQ:
<https://goatcorp.github.io/faq/xl_troubleshooting#q-how-do-i-whitelist-xivlauncher-and-dalamud-so-my-antivirus-leaves-them-alone>
