## Release notes

This release includes UI localization-theme and release documentation updates.

### Changes
- Fixed launcher language theme colors so each launcher language now maps to its own country flag-inspired palette.
- Fixed local/non-official builds to skip production auto-update checks (for reliable first-run testing from `Setup.exe`).
- Added a Russian README and linked it from the main README, while preserving existing links for other languages.
- Fixed release-related links in the main README.
